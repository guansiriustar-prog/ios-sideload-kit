# 04 · 机型与系统版本适配

> 数据来源：各项目官方 README / Release 说明 + 本次在 **iPhone 15 Pro Max（A17 Pro）+ iOS 26.0.1（Build 23A355）** 上实测。
> 版本随时在变，实操前请以官方 Release 页为准。

---

## 一、无越狱方案（本文主线）

| 工具 | 支持的 iOS | 支持机型 | 说明 |
|---|---|---|---|
| **SideStore** | **iOS 15.0 及以上**（实测 26.0.1 通过；官方文档写 15.0+） | 所有能装 iOS 15 的 iPhone / iPad | 免费 Apple ID 即可；需要 Wi-Fi + 本地回环 VPN |
| **LiveContainer** | **iOS 15.0 及以上**（3.8.x，`MinimumOSVersion = 15.0`；实测 26.0.1 通过） | 同上 | 容器方案；需从 SideStore 导入证书 |
| **StikDebug**（JIT） | **iOS 17.4 及以上**（26.x 官方标注 Supported，但部分 App 需自行适配） | 同上 | 已被 App Store 下架，需用 IPA 侧载 |
| **LocalDevVPN** | iOS 16 及以上（App Store 上架版） | 同上 | SideStore 刷新/安装的必需品 |

> 越新的系统**不会**更容易失败：侧载不依赖系统漏洞，依赖的是你自己的开发者证书。真正会"卡死登录"的是**苹果服务端的接口变更**（见 [02 · 排错](02-troubleshooting.md)）。

### 已知的版本相关坑

| 现象 | 涉及版本 | 说明 |
|---|---|---|
| 登录报 `-22411` | 客户端版本 **< SideStore 0.7.0-20261013** | 缺苹果新 2FA 响应支持；`0.6.4`、`0.7.0-20260911`、LC+SS 组合包内置的 `20260918` 都会中招 |
| 登录报 `503` / `isn't in the correct format` | 所有客户端 | 只要 anisette 身份是 Mac/Android 就会中招，与 App 版本无关 |
| `iPhone 17` 系列部分工具不支持 | 特定工具 | 苹果在部分新芯片上引入 MTE 等防护，某些工具明确声明"不支持 iPhone 17 全系"（例如部分文件管理类工具） |

## 二、TrollStore（巨魔商店）现状

**结论：iOS 17.0.1 及以上永远装不了原版 TrollStore。**

| iOS 版本 | 原版 TrollStore | 原因 |
|---|---|---|
| 14.0 – 16.6.1 | ✅ 支持（分 arm64 / arm64e 不同安装方式） | CoreTrust 漏洞存在 |
| 16.7 – 16.7.2 | ❌ 不支持 | 两个 CoreTrust 漏洞均已修复 |
| **17.0** | ✅ 支持 | 第二个 CoreTrust 漏洞仍在 |
| **17.0.1 及更新（含 iOS 18 / 26 全系）** | ❌ **永远不支持** | CoreTrust 已修，除非苹果第三次出错 |

**TrollStore Lite**：同作者的"越狱版巨魔前端"（Havoc 源，声明支持 iOS 14.0 – 26.0.1），但它**必须先越狱**才能用。

**给用户的正确话术**：
- "你的 iOS 26.0.1 装不了巨魔，这不是姿势问题，是苹果把漏洞修了。" 
- "网上说'iOS 26 一键巨魔'的，基本都是卖证书或引流，别装描述文件、别把 Apple ID 给第三方。"
- "侧载（SideStore）能达到'装任意 IPA'的效果，但拿不到系统级插件/改状态栏那种能力。"

## 三、越狱现状（想用 TrollStore Lite 或系统级插件才需要）

| 越狱工具 | 支持芯片 | 支持的 iOS |
|---|---|---|
| **Dopamine 3**（rootless，半不完美越狱） | A12 / A12X / A12Z / A13 | 16.6 – 18.7.1，**外加 26.0 – 26.0.1** |
| 同上 | A14 / M1 | 16.6 – 17.3.1 |
| 同上 | **A15 / A16 / A17 / M2**（iPhone 13 – 15 系列） | **16.5.1 – 17.3.1**（**不含 iOS 26**） |
| 同上 | A10 / A9 / A11 / A8 等老机型 | 见其 Release 说明 |

**对号入座（重要）**：
- 本文实测机 **iPhone 15 Pro Max = A17**：Dopamine 3 只支持到 **17.3.1**，**iOS 26 无法越狱** → 因此也**装不了 TrollStore Lite**。
- 反过来，能越狱 iOS 26 的只有 **A12/A13**（iPhone XS～iPhone 11、SE2 等）—— 机型老，与"最新机型"无缘。
- 结论：**新机型 + 新系统 = 放弃越狱/巨魔，走 SideStore 侧载这条正路。**

## 四、其他侧载方式对比（供用户横向参考）

| 方案 | 需要电脑 | 有效期 | 上限 | 备注 |
|---|---|---|---|---|
| **SideStore**（本文推荐） | 仅首次 | 7 天（可自动续） | 3 个 App | 免费、开源、社区活跃 |
| **LiveContainer**（配合） | 仅首次 | 跟随 SideStore | 容器内不限 | 无推送，兼容性略差 |
| AltStore / AltServer | **每次刷新都要** | 7 天 | 3 个 App | 需要电脑常开同 Wi-Fi |
| Sideloadly / iLoader 直装 | 每次安装都要 | 7 天 | 3 个 App | 最简单但最依赖电脑（本文的保底通道） |
| 企业证书 / 第三方签名商店 | ❌ | 随时被吊销 | 不限 | **高风险**：证书来源不明、可能拿到你的 Apple ID，随时失效 |
| 付费开发者账号（$99/年） | 仅首次 | 1 年 | 100 个 App | 长期重度使用者值得 |

## 五、适配自查清单（给别人装机前问这 5 句）

1. 什么机型？（决定能不能越狱、有没有 MTE 类限制）
2. 系统版本？`设置 → 通用 → 关于本机 → 软件版本`（决定 SideStore/StikDebug 是否可用、巨魔是否有戏）
3. 有没有设置**锁屏密码**？（没有 → 签名必失败）
4. 有没有 Wi-Fi？（没有 → 侧载基本不可用）
5. 有没有**专用小号 Apple ID**？（没有 → 建议先注册一个，别用主力号）

## 六、一句话总结表

| 用户情况 | 推荐方案 |
|---|---|
| iOS 15–26，想装几个 App，图省事 | **只用 SideStore** |
| iOS 15–26，要装很多 / 模拟器 / 多开 | **SideStore + LiveContainer**（+ StikDebug 开 JIT） |
| 想玩**系统级插件、改状态栏** | 只有越狱能做到；先查自己的芯片是否在支持表里 |
| 问「巨魔」且系统 ≥ 17.0.1 | 明确告知**不可能**，并给出 SideStore 替代方案 |
| 老机型（A12/A13）+ iOS 26.0.1 | 可考虑越狱（Dopamine 3），此时 TrollStore Lite 才用得上 |
